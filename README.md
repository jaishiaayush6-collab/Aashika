# AJ Code Lab

नेपाली भाषामा coding, Python, web/app development, networking र सुरक्षित cybersecurity अवधारणा सिकाउने GitHub Pages website।

## मुख्य सुविधाहरू
- Responsive dark/light UI
- 8 वटा starter learning paths र lesson outlines
- 22 programming / markup / query languages को learning roadmap
- Python playground (Pyodide CDN आवश्यक) र JavaScript console playground
- Simulated network diagram, demo password safety checker र defensive web security checklist
- Project ideas र mobile-friendly navigation

## GitHub Pages मा चलाउने
1. ZIP extract गर्नुहोस्।
2. `index.html`, `style.css`, `app.js`, `README.md` लाई GitHub repository को root मा upload गर्नुहोस्।
3. Repository → **Settings → Pages** खोल्नुहोस्।
4. **Deploy from a branch** छान्नुहोस्, `main` र `/ (root)` select गरेर Save गर्नुहोस्।
5. केही समयपछि GitHub Pages ले दिएको URL खोल्नुहोस्।

## Local preview
फोल्डर खोलेर `index.html` browser मा खोल्न सकिन्छ। Python playground को लागि इन्टरनेट चाहिन्छ, किनकि Pyodide CDN बाट load हुन्छ। JavaScript playground browser मै चल्छ।

## सुरक्षा सीमा
Cyber Lab का सबै अभ्यास simulated र defensive छन्। यो project ले कुनै वास्तविक website, IP, Wi‑Fi वा device scan/attack गर्दैन। वास्तविक system मा security testing गर्न स्पष्ट लिखित अनुमति र तय गरिएको scope अनिवार्य हुन्छ।

## विस्तार गर्नुपर्ने production सुविधाहरू
यो GitHub Pages static starter हो। वास्तविक user accounts, progress sync, server-side code execution, database र instructor dashboard चाहिएको अवस्थामा secure backend/API तथा database нिर्माण गर्नुपर्छ। Browser मा अज्ञात code चलाउँदा जोखिम हुन सक्छ; आफ्नै code मात्र प्रयोग गर्नुहोस्।
