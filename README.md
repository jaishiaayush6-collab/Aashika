## Publish directly on GitHub Pages
1. Create a new GitHub repository, for example `AJ-CODELAB`.
2. Extract this ZIP on your computer.
3. Upload the contents of this folder (`index.html`, `style.css`, `script.js`, `README.md`) to the **root** of the repository. Do not upload the ZIP itself as the website.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish. Your site address will look like `https://YOUR-USERNAME.github.io/AJ-CODELAB/`.

## Run locally
Open `index.html` in a modern browser. No VS Code or install step is required.
